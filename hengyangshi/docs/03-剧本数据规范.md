# 《恒仰市·规则怪谈》剧本数据规范 v1.0

> 本文档是 11 张地图的数据契约。所有地图 `data/maps/*.js` 必须严格遵守本规范；
> 数据由 `js/engine.js` 载入、`tools/validate.mjs` 校验、`tools/playtest.mjs` 自动试玩。
> 写作者只允许修改自己被分配的地图文件，**禁止修改** `js/`、`css/`、`index.html`、
> `data/world.js`、`data/items.js` 及其他人的地图文件。

---

## 0. 一句话总纲

本作是**纯文字多选规则怪谈**：玩家在恒仰市的 11 个异常现场中，依照（或不依照）一份份
自相矛盾的守则做出选择；错误会加深感染、损耗精神、耗尽体力，触发即死；正确选择可以
降低感染、恢复精神，但**体力值只能下降，永不回升**。每一个原视频中的"错误点"都要被
展开为多个"看似合理"的选择，并在剧情里给出详细解说，让没看过原视频的读者也能读懂故事。

## 1. 文件与加载

```
data/maps/map01.js   ... 每一张地图一个文件，文件内只做两件事：
                        (1) 如有本图专属剧情道具，先 HY.registerItems({...})
                        (2) HY.registerMap({...})
```

文件包装（必须一模一样，防止变量泄漏）：

```js
/* map05 · 百果村 */
(function () {
  "use strict";

  HY.registerItems({
    /* 本图专属剧情道具（不出现在商店） */
  });

  HY.registerMap({
    /* ...地图对象... */
  });
})();
```

地图文件由 `index.html` 中的 `<script src="data/maps/map05.js"></script>` 加载；
加载顺序不影响功能（每张地图独立注册），但 `data/items.js`、`data/world.js` 必须先加载。

### 地图硬性指标（验收线）

| 指标 | 最低要求 |
|---|---|
| 节点数 | ≥ 26（推荐 30-45） |
| 结局数 | ≥ 4：至少 1 个 `true` 或 `hidden`、≥2 个 `death`、≥1 个 `escape`/`become` |
| 规则条目 | ≥ 10 条，覆盖原视频守则的主要条款 |
| 情绪卡 | ≥ 5 张 |
| 剧情解说 | ≥ 6 个节点带 `insight`，结局 `analysis` ≥ 3 段 |
| 选择点 | ≥ 22 个含选项的节点；每个节点 2-4 个选项 |
| 门槛选择 | ≥ 5 个使用 `req`（道具/感染/精神/flag）的选项 |
| 即死 | ≥ 3 个 `dead` 即死选项，分布在不同的错误点 |
| 体力预算 | 一条"最稳妥路线"累计体力损失 25-60；任何单次损失 ≤ 25（即死除外） |

## 3. 节点（nodes）

`nodes` 是 `{节点id: 节点对象}` 的字典。节点 id 建议 `n001` 递增，结局节点建议 `end_xxx`。

```js
nodes: {
  n001: {
    chapter: "第一章 · 进村",      // 选填，章节小标题
    bg: "village",                // 选填：home|train|airport|redzone|village|mountain|
                                  //       school|academy|newyear|stage|city|void
    lines: [                      // 必填，正文段落数组（每项一段，建议 2-6 段，共 150-450 字）
      "中巴车在村口停下时，天已经擦黑。",
      "槐花的香味浓得发苦。你看见村口老槐树下坐着一个包豆子的老太太……"
    ],
    insight: {                    // 选填，剧情解说（可折叠面板）
      title: "剧情解说 · 白果村的规矩",
      lines: ["原视频里，这段游客须知最容易被忽略的是……", "……"]
    },
    whisper: ["你听见有人在很近的地方数数。"], // 选填：精神值 ≤ 40 时追加显示的幻听段落
    drift:   ["你忽然能听懂槐树叶子摩擦的声音。"], // 选填：感染值 ≥ 60 时追加显示的污染段落
    fx: { infection: 2, sanity: -4, stamina: -2 },  // 选填，进入本节点立即结算
    setFlags: ["f_entered_village"],   // 选填，进入本节点设置 flag
    clearFlags: [],                    // 选填
    unlockRules: ["map05_r1"],         // 选填，进入本节点解锁规则档案
    awardEmotions: ["em05_lantern"],   // 选填，进入本节点获得情绪卡
    items: { add: ["map05_note_li"], remove: [] }, // 选填，进入本节点获得/失去道具
    cp: 0,                             // 选填，进入本节点获得选择次数点（少用）
    choices: [ /* 见第 4 节 */ ]        // 与 ending 二选一
  },

  end_true: {
    bg: "village",
    ending: {
      type: "true",                // death | fail | escape | become | true | hidden
      title: "结局 · 逆流而上",
      subtitle: "木筏浮起的那一寸，是阿音最后能做的事",
      lines: [ "…", "…" ],        // 结局正文 2-6 段
      analysis: [                  // 剧情解析 ≥3 段（可以是对象数组）
        { title: "解析一 · 阿音是谁", lines: ["…"] },
        { title: "解析二 · 你为什么能走", lines: ["…"] },
        { title: "解析三 · 视频里没拍出来的部分", lines: ["…"] }
      ],
      awards: {                    // 选填
        items: ["it_raft_cord"],   // 永久获得的证物（必须在上文全局道具表里）
        emotions: ["em05_raft"],   // 额外补发的情绪卡
        rules: []                  // 额外补发的规则档案
      },
      cp: 26                       // 选填，覆盖默认奖励
    }
  }
}
```

### 节点规则

1. 每个节点必须有 `lines`（≥1 段），或者有 `ending`。
2. 节点要么有 `choices`（2-4 个），要么有 `ending`，不能两者都有、也不能都没有。
3. `fx.stamina` **只能为负数或 0**；`fx.infection` 建议 0-15；`fx.sanity` 建议 -25 ~ +10。
4. 数值结算顺序：选择 fx → 目标节点 fx。任何时刻感染 ≥100 / 精神 ≤0 / 体力 ≤0 立即判定死亡。
5. `whisper`/`drift` 只用于氛围，不影响数值。
6. 剧情解说 `insight` 是给"没看过原视频的人"看的，要写清：原视频这一段讲了什么、
   规则为什么这样定、村民/主角的真实处境是什么。**不要只复述正文。**

## 4. 选项（choices）

```js
choices: [
  {
    text: "退回门内，把门闩插好，退到客厅中间站着不动。",  // 必填
    tag: "安全",              // 必填：安全|危险|代价|道具|异常|情感|即死|真相
    hint: "你想起了便条上的第二条。",   // 选填，小字提示，不剧透结果
    req: {                    // 选填，门槛（全部满足才可选）
      items: ["it_ash"],      // 需要持有道具（本局背包里）
      infectionMin: 30,       // 感染值 ≥ 30 才出现
      infectionMax: 70,
      sanityMin: 20,
      sanityMax: 55,          // 精神值 ≤ 55 才出现（如"濒临崩溃时的直觉"）
      staminaMin: 10,
      flags: ["f_saw_mirror"],      // 必须已设置
      notFlags: ["f_dad_returned"]  // 必须未设置
    },
    lockText: "缺少「香灰符」；或你还没看清门外的倒影", // 选填，锁定时显示的提示
    hidden: false,            // 选填 true：条件不满足时该选项直接不显示（默认 false：灰色锁定+提示）
    fx: { infection: 8, sanity: -12 },   // 选填，选择后立即结算
    setFlags: ["f_door_locked"],         // 选填
    clearFlags: [],
    items: { add: [], remove: ["it_ash"] }, // 选填，消耗/获得道具
    cp: 2,                    // 选填，立即获得选择次数点
    result: ["门外的敲击声停了三秒，又响起来。"], // 选填，选择后的即时反馈（先显示，再进目标节点）
    next: "n012",             // 目标节点 id（与 dead 二选一）
    dead: {                   // 选填，即死：体力瞬间归零
      title: "即死 · 你开了门",
      lines: ["门缝合上的最后一刻，你看见门外站着的不是爸爸。", "……"],
      analysis: ["原视频里，规则第二条是唯一一条用加粗警告的条款……"] // 选填
    },
    end: "end_xxx"            // 选填，等价于 next 指向一个结局节点；与 next 二选一
  }
]
```

### 选项规则

1. **每一个原视频里的"错误点"都要做成选项，并且至少提供 2 个"看起来都合理"的分支**
   （一个更安全、一个更诱人/更合情理），而不是明显的对错二选一。
2. `dead` 是**即死**：直接显示体力归零的死亡结局，不发常规死亡奖励。
3. `req` 门槛用于实现"并非所有选择都能实时触发"：
   - 道具门槛：`lockText` 写"需要「XX」"，`hidden: false` 时玩家能看到灰色选项，知道有别的路；
   - 数值门槛：感染值高能"听懂"某些东西、精神值低会出现疯狂选项、精神值高才能保持清醒判断；
   - flag 门槛：剧情伏笔，如 `f_saw_reflection`。
4. 每个节点的选项要**互相排斥地覆盖**：不要出现"选 A 然后回到同一节点"的无限循环。
5. 选项文字使用第一人称动作/心理，不要写成"正确选项/错误选项"。
6. 结局不要只写"你死了"。死亡结局也要有 2-4 段正文 + 一段解析，说明违反了哪条规则、
   原视频里这一步为什么致命。
7. **体力值只能下降**：任何选项、节点、道具都不能 `stamina: +N`（校验器会报错）。

## 5. 结局类型与奖励

| type | 中文标签 | 默认选择次数点 | 说明 |
|---|---|---|---|
| `death` | 死亡 | 2 | 即死、感染、崩溃等一切死亡 |
| `fail` | 溃败 | 4 | 没死，但彻底失败（被困、被抹除记忆等） |
| `become` | 异化 | 10 | 被同化：成为村民/家族一员/优秀毕业生/安抚员/节点 |
| `escape` | 逃离 | 14 | 活着离开现场，但没看到真相 |
| `true` | 真相 | 26 | 看破规则背后的真实逻辑并活着离开 |
| `hidden` | 隐藏 | 40 | 需要跨图证物/特殊门槛，改写故事 |

- 首次通关任意结局额外 +10；首次达成 `true` 额外 +12；`hidden` 额外 +20。
- `ending.awards.items` 中的道具**永久加入存档**（跨图证物），必须使用全局道具 id（见 data/items.js）。
- 每张地图必须有一个会对后续地图产生影响的真结局证物（见《地图设计总纲》分配表）。
- 结局 `analysis` 是"整个流程详细剧情解说"的落点：必须包含
  ①原视频剧情梗概 ②角色真实身份/动机 ③规则怪谈的隐喻与世界观 ④玩家的选择复盘。

## 6. 数值系统

| 数值 | 初始 | 范围 | 规则 |
|---|---|---|---|
| 感染值 | 0（部分图 5-20） | 0-100 | 上升为主；≥100 立即异变死亡。感染值高会解锁"听懂/看见"的门槛选项，也更容易被同化。 |
| 精神值 | 80（部分图 60-85） | 0-100 | 恐怖、幻觉、亲人异化会扣；清醒、安全屋、道具可回。≤0 精神崩溃。≤40 触发 `whisper` 幻听。 |
| 体力值 | 100（部分图 80-95） | 0-100 | **只能下降**。奔跑、熬夜、攀爬、挣扎消耗；≤0 即死。**没有任何回复手段**，所以路线规划本身就是"用多少体力换多少真相"。 |
| 选择次数点 | 存档资源 | - | 通关获得；在商店永久购买道具；每张图重新开始时道具次数重置。 |

**平衡基准**：一条"最稳妥路线"累计体力损失目标 25-60。若你的最差路线在 10 个节点内
就耗尽体力，说明体力惩罚过重，请下调数值。

## 7. 道具

- 全局道具（可购买/跨图证物）定义在 `data/items.js`，用 `HY.registerItems({...})` 风格。
- 本图剧情道具写在 `map.localItems` 或地图文件开头的 `HY.registerItems` 里，`shop: false`。
- 本局背包 = 玩家永久拥有的所有道具（每次入图自动带入，次数重置）+ 本图拾取的剧情道具。
- 使用道具（HUD 右上"道具"）只对带 `effect` 的道具生效，消耗一次 `uses`。
- 跨图证物（true/hidden 结局授予）必须使用全局 id，见下表：

| 地图 | 真结局证物 id | 名称 | 在后续地图的用途 |
|---|---|---|---|
| map01 | `it_badge_tsp` | 特警的编号牌 | 在列车/机场自证"幸存者" |

## 8. 写作风格

- 简体中文；沉浸式第二人称（"你"）叙事；每段 1-3 句，短促，留白。
- 恐怖来自**规则的二义性、亲人的熟悉感、日常物件的错位**，而不是血浆。
- 允许并鼓励：感官细节（气味、温度、声音）、身体反应（汗、耳鸣、心跳）、
  日常对话的轻微失控（"妈妈笑着说没事，但你看见她手指在抠掌心"）。
- 每张图必须出现原视频中的**标志性文本**：守则原文改写、主角独白、结尾旁白。
- 不要写作者旁白式的"这里暗示了……"——解析请放进 `insight` / `analysis` 字段。
- 不要出现真实网址、二维码、血腥猎奇、性内容；死亡以"消失/融合/成为"呈现。
- 至少 3 处让玩家"犹豫"的道德/情感选择（例如：救不救、说不说、回不回头）。

## 10. 自检

在项目根目录运行（需要 Node.js）：

```bash
node tools/validate.mjs --map map05
```
