## 1. map01 居家日记（Lead）

- **身份**：失踪两个月的女儿。记忆停在公园的洞，醒来已站在家门口。
- **初始**：感染 0 / 精神 82 / 体力 100；携带 `it_note_mom`、`it_phone`（旧手机）。
- **规则文件**：妈妈的便条（7 条，逐条随剧情解锁）。
- **核心场景**：回家 → 第一夜（窗帘/天空）→ 饮水机（生水）→ 父亲车祸与门外归来的父亲 → 停电（镜面融合） → 母亲床前的“该融合了” → 逃出楼道 → 特警 → 列车。
- **关键错误点**：看天空、喝生水、回忆梦境、追问/揭穿归来的父亲、停电乱动、开门、与镜中倒影对视、回应“融合”、在特警面前自称回归者。
- **结局**：死亡（天空/生水/开门/崩溃）、异化（融合）、逃离（特警送上列车）、真相（保留母亲的便条与家庭证据，让特警确认“幸存者”，获得 `it_badge_tsp`）、隐藏（用旧手机播放家庭视频，唤回父亲残存的一瞬，拿到通往车站的钥匙）。
- **情绪卡**：亲人异化 · 被替代 · 镜像与倒影 · 记忆不可靠 · 无处可逃。

## 3. map03 离开恒仰市的方法（Lead）

- **身份**：从融会中心站台转乘到机场的旅客。
- **初始**：感染 20 / 精神 62 / 体力 78。
- **规则文件**：机场旅客须知（7 条）+ 健康申报/安检补充 + 从各处听来的“错误版本”。
- **核心场景**：出发大厅 → 红/黄/蓝/绿/常规五条通道 → 申报表与腕带 → 蓝色候机区 → 安检二次核验 → 特产店推销员 → A01/A05 登机口 → 检票闸机 → 清洁工与垃圾桶 → 二楼旅客服务中心 → 时钟。
- **关键错误点**：谎报行程、用异常的申报表格、让腕带“活性化”、接受推销、收下红色充电宝、强行通过异常闸机、进入绿色专用通道、回答“校准”广播、长时间凝视时钟、登上 A01/A05。
- **结局**：死亡/被清理、异化（绿色三角）、溃败（蓝色候机区无限等待）、逃离（按常规流程“登机”实际上被转化）、真相（清洁工七秒/时钟符号/外界证物 → `it_pass_outside`）、隐藏（用稳定仪帮助红区旅客苏醒，从红区背面找到员工通道）。
- **情绪卡**：规则二义 · 集体同化 · 被注视 · 无处可逃 · 虚假的救赎 · 成为工具/节点。

## 12. 写作提醒

1. **原视频的守则原文是最重要的素材**：尽量保留原文的句式与细节（"乌鹏船船头悬红灯笼为极"、"筷子需横置于碗上"、"三七二十一"），玩家会认出它们。
2. **每个错误点至少两个“都说得通”的选项**：一个更像守则、一个更像常识；有时候常识才是陷阱。
3. **不要所有选择都实时可见**：道具/感染/精神的`req`门槛要自然，让玩家在失败后回想“如果当时有那个东西”。
4. **解说不是复述**：`insight` 要告诉玩家“原视频里这一段其实在说什么”，`analysis` 要回答“这个故事到底讲了一个什么人”。
5. **每张图至少有 1 个选择让人沉默三秒**：救不救、说不说、回不回头、要不要开门。
6. **数值为叙事服务**：体力只降不升，所以“走到最后”本身就是代价；不要用数值惩罚代替剧情。
7. 禁止：真实网址/二维码、血腥描写、性内容、政治影射、对现实城市与真实人物的指涉。恐怖以“日常被改写”为主。
